**Назначение:** приложение для учёта съеденного за день — калории, БЖУ, разнообразие рациона. Пользователь загружает файлы (например, списки продуктов или фото еды), видит статистику.

---

## Основные экраны:

**Главная (Dashboard):** прогресс по калориям, БЖУ, список приёмов пищи
**Дневник питания:** добавление приёмов пищи, выбор продуктов, редактирование, удаление
**Статистика:**	графики по калориям и разнообразию за неделю/месяц
**Загрузка файлов:** форма загрузки пользовательских файлов (списки продуктов, фото)
**Профиль:** цели по калориям, настройки

## Пользовательские сценарии:

1. Пользователь открывает главную → видит сводку дня → переходит в дневник → добавляет приём пищи → возвращается на главную → видит обновлённые данные.
2. Пользователь открывает статистику → выбирает период → видит графики.
3. Пользователь загружает файл со списком продуктов → получает подтверждение загрузки.
